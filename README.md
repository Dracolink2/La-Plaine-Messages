# La-Plaine-Messages
Tout les messages pour La Plaine à partir du 10/11/2026, avec des notes de dev, et juste des infos sur les nouvelles versions du jeu avec aussi des conseils pour optimiser le jeu en plus de nos optimisations.

Pour les infos sur comment optimiser le jeu, en plus de nos optimisations et des paramètres en jeu, allez sur la branche "optimiser"
Pour les infos en générales sur les versions du jeu, allez sur la branche "versions"
Pour les infos sur où trouver chaque dépôts, et à quoi ils servent, allez sur la branche "où?"
Pour les notes de dev, c'est sur cette branche, avec la date, et si besoin, le numéro du message ( si y'en a plusieurs par jour)
Et enfin pour toutes les autres petits infos, allez sur la branche "autres"
